## Read Me
The processing script is written by Jess Shue

The processing script can be run on intra annual or biannual data

First download data from arcGIS online:
- go to SCBI group
- click on NZCBI biannual dendrometers 2026
- click on feature layer NZCBI dendrometers
- hit export data
- Download with **FIELD NAMES** not display names
